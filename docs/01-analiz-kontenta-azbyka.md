> домен `azbyka.ru` закрыт сетевой политикой (HTTP 403 на прокси). Поэтому

## 3. Типы данных и способы их получения

| Тип | Где | Как забирать |

| HTML-страницы | все разделы | Краулер с белым списком префиксов путей. Энциклопедия лежит в корне домена, поэтому нужен отдельный список slug-ов (из карт разделов `/<раздел>/karta-sajta` и sitemap) |
| EPUB/PDF книг | Отечник | Кнопки скачивания на странице произведения; **требуется авторизация** (cookie сессии зарегистрированного пользователя) |

Есть готовая сторонняя утилита [dimchansky/azbyka-dl](https://github.com/dimchansky/azbyka-dl) (Go), на сайте есть инструкция [для Download Master](https://azbyka.ru/audio/download-master.html) |
| PDF-ноты | Клирос | Прямые ссылки на страницах произведений |

| Изображения | Календарь (иконы), art, foto, shemy | Вместе с HTML, через тот же краулер |

## 5. Предлагаемые очереди сохранения

**Очередь 0. Сделать сразу, без разработки.**
- Установить официальное приложение [«Моя православная библиотека»](https://azbyka.ru/prilozhenie-moja-pravoslavnaja-biblioteka) (Android, iOS, AppGallery). В нём можно скачать всю библиотеку или рубрику для офлайн-чтения: около 2 500 текстовых и около 300 аудиокниг.
- Действительно энергонезависимый минимум — бумага: напечатать Евангелие, Псалтирь, Молитвослов и Последование ко Причащению.

**Очередь 1. Ядро (A), небольшой объём, максимальная ценность.**
Библия со всеми переводами и толкованиями, Молитвослов (ЦС и гражданский шрифт), Псалтирь, богослужебные тексты (Октоих, Минея, Триодь, «Богослужения сегодня»), календарь (данные на 10–20 лет и месяцеслов с иконами), энциклопедия, церковное право, словари ЦСЯ, тексты Отечника в HTML и EPUB.

**Очередь 2. Желательное (B).**
PDF Отечника, вопросы и ответы, цитаты, схемы, художественная литература, ноты Клироса, Азбука искусства, паломник, детский раздел, аудио Писания и Псалтири, аудиокниги.

**Очередь 3. Тяжёлое (C).**
Остальное аудио, видео, фото, рецепты, семейные разделы.

**Не сохранять.** Форум, знакомства, новости, магазин, личные кабинеты.

## 6. Формат офлайн-хранилища (предложение)

- **ZIM + Kiwix** для HTML-разделов. Это формат офлайн-Википедии: один сжатый файл со встроенным полнотекстовым поиском. Читается [Kiwix](https://kiwix.org) на Windows, Linux, macOS и Android. `kiwix-serve` на Raspberry Pi раздаёт библиотеку по локальному Wi-Fi на весь приход. Сборка возможна через [zimit](https://github.com/openzim/zimit) или из собственного обхода через `warc2zim`.
- **Файловое дерево** для EPUB, PDF, MP3/M4B и PDF-нот. Его можно читать без специального ПО, на e-ink читалках с низким энергопотреблением.
- **SQLite** для структурных данных: календарь из API, Библия постишно, правила, цитаты. Это позволит позже сделать своё лёгкое офлайн-приложение.
- **Железо.** Лучше несколько копий на разных носителях: SSD или HDD, плюс копия на другом устройстве в другом месте. Минимальный сервер — Raspberry Pi или неттоп с питанием от аккумулятора или солнечной панели.

## 7. Риски и организационные вопросы

1. **Сетевой доступ.** Для работы из облачного окружения в настройках среды нужно разрешить домены `azbyka.ru` и `azbyka.org`, а также домены CDN, если медиа отдаются с них. Полную многотерабайтную выгрузку разумнее запускать на собственном сервере или NAS: облачный контейнер эфемерный и имеет ограниченный диск. Здесь стоит писать и отлаживать скрипты.
2. **Авторизация.** Скачивание EPUB/PDF из Отечника доступно только зарегистрированным пользователям, для API календаря нужно одобрение администратора. Подать заявку на API стоит заранее.
3. **Нагрузка на сайт.** Портал содержит благотворительный фонд. Обход должен быть вежливым: соблюдать `robots.txt`, делать не больше 1–2 запросов в секунду, работать в ночные часы, указывать честный User-Agent с контактом и докачивать возобновляемо, без повторных запросов.
4. **Авторские права.** Значительная часть Отечника и художественной литературы — современные издания с действующими правами. Личный или приходской офлайн-архив на случай ЧП и публичная раздача копии — юридически разные вещи. Публиковать зеркало не нужно.
5. **Самый короткий путь — договориться.** Стоит написать в Фонд «Азбука веры» ([azbyka.org/fond](https://azbyka.org/fond/portal-azbuka-very/)) и объяснить цель. Приложение «Моя православная библиотека» уже умеет выгружать библиотеку целиком, значит у фонда есть готовые пакеты книг. Официальный дамп был бы надёжнее и чище парсинга и не нагружал бы сайт.
6. **Динамика.** Календарь и «Богослужения сегодня» генерируются по дате, поэтому одного снимка мало (см. раздел 2.3).
7. **Церковнославянский шрифт.** Для корректного отображения ЦС-текстов офлайн нужно сохранить веб-шрифты портала (Ponomar, Triodion и т.п.) или положить рядом с копией свободные шрифты Ponomar Unicode или Triodion Unicode (проект ponomar.net).

## 8. Следующие шаги

1. Открыть доступ к `azbyka.ru` и `azbyka.org` в настройках окружения. Снять `robots.txt`, `sitemap.xml` и карты разделов (`/<раздел>/karta-sajta`), получить точный список URL и объёмы.
2. Пробный обход 1–2 % каждого раздела ядра, чтобы получить реальные размеры и шаблоны URL.
3. Зарегистрировать аккаунт на портале и подать заявку на API календаря.
4. Написать письмо в фонд с вопросом об официальной выгрузке.
5. Реализовать обходчик очереди 1 с выходом в WARC → ZIM, а также EPUB и SQLite.
