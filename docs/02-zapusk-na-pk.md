# Как собрать архив на своём компьютере

Сбор идёт на вашем ПК: он должен открывать azbyka.ru, и на нём должно
хватать места на диске. Скрипт можно останавливать в любой момент.
При следующем запуске он продолжит с того же места, ничего не
перекачивая. Всё, что нужно, — Python и этот репозиторий.

## 1. Что понадобится

| | Минимум | Рекомендуется |
|---|---|---|
| Компьютер | любой с Windows 10/11, Linux или macOS | тот, что может работать неделями без выключения |
| Python | 3.11 | 3.12–3.13 |
| Диск | 1 ТБ (без видео) | внешний диск 4 ТБ (всё, с видео ≈ 1,5–2,5 ТБ) |
| Интернет | безлимитный | от 50 Мбит/с |

Объёмы и сроки по разделам — в `docs/03-obem-i-sroki.md` (замеры на живом
сайте). Коротко: около 1 млн страниц и 1,5–2,5 ТБ файлов, примерно две
недели непрерывной работы.

## 2. Установка (один раз)

1. **Python.** Скачайте установщик с https://www.python.org/downloads/.
   При установке **обязательно отметьте галочку «Add python.exe to PATH»**.
   На Windows 10/11 можно и из командной строки: `winget install Python.Python.3.12`.
2. **Программа.** На странице репозитория на GitHub нажмите
   **Code → Download ZIP** и распакуйте архив, например в `D:\azbyka-reserv`.
   Если установлен git: `git clone https://github.com/arsi945/azbyka-reserv`.
3. **Место для архива.** Лучше отдельный (внешний) диск и **короткий путь**,
   например `E:\azbyka`. Длинные пути Windows не любит.

## 3. Запуск сбора

**Windows:** дважды щёлкните `zapusk.bat`. Архив будет в папке `data` рядом
со скриптом. Чтобы сохранять на другой диск, откройте командную строку в
папке программы и выполните:

```
zapusk.bat E:\azbyka
```

**Linux / macOS:**

```
./zapusk.sh /mnt/disk/azbyka
```

В окне раз в 15 секунд печатается сводка:

```
21:40:15 готово 15234 | в очереди 412877 | ошибок 3 | нужен вход 0 | сохранено за сеанс 1.2 ГБ | 2.0 стр/с | 1.4 МБ/с
```

Что важно знать:

- **Окно можно закрыть** (или нажать Ctrl+C) — сбор остановится. Повторный
  запуск продолжит с места остановки. Недокачанные большие файлы
  докачиваются, а не начинаются заново.
- `zapusk.bat` сам перезапускает сбор после сбоев (например, если пропал
  интернет). Останавливается он только в трёх случаях: всё скачано,
  кончилось место на диске или Windows не может проверить сертификат сайта.
  В последнем случае на экране будет команда, которую нужно выполнить.
- Если интернет пропал, программа заметит это и будет ждать, не помечая
  страницы ошибочными. Когда сеть вернётся, сбор продолжится сам.
- Не запускайте два `zapusk.bat` на одну папку: второй сам откажется.
- Пока идёт сбор, Windows не уходит в сон. Выключать компьютер можно, после
  включения просто запустите `zapusk.bat` снова.
- **Не щёлкайте мышью внутри чёрного окна**: в Windows это ставит вывод на
  паузу. Программа отключает такой режим сама, но если окно всё же
  «замерло», нажмите Esc.
- Сначала качается самое ценное: Библия, молитвослов, богослужебные тексты,
  календарь, святоотеческая библиотека и энциклопедия. Потом остальные
  тексты, книги, ноты и аудио. Видео идёт последним. Если интернет пропадёт
  на середине, главное уже будет сохранено.
- Скорость намеренно ограничена (около 1,4 запроса в секунду). Сайт
  содержит благотворительный фонд, и перегружать его нельзя. Не уменьшайте
  `min_delay`.
- **Обновление программы.** Скачайте новую версию и замените файлы
  программы, не трогая папку `data`. Запустите `zapusk.bat`. Если изменились
  правила обхода, программа сначала (без интернета) заново разберёт уже
  скачанное и дополнит очередь. Это может занять несколько часов на большом
  архиве; если прервать, продолжится с того же места.

## 4. Как следить за ходом

```
servis.bat status          (Linux: python3 -m azbyka_reserv status --data ПАПКА)
```

Покажет, сколько скачано по разделам, объём, ошибки и что отсечено
правилами. Подробный журнал лежит в `data\logs\`.

Если накопились ошибки (например, сайт временно не отвечал):

```
servis.bat retry
```

После этого снова запустите `zapusk.bat`.

## 5. Книги «Отечника» (EPUB/PDF/сканы) — нужен вход на сайт

Тексты всех книг «Отечника» сохраняются в любом случае, как страницы. Но
готовые файлы для читалок (EPUB, PDF, сканы оригиналов) сайт отдаёт только
вошедшим пользователям. Без входа обходчик их не запрашивает, а в `status`
показывает строку «нужен вход (cookies_file)». Чтобы скачать и их:

1. Зарегистрируйтесь и войдите на azbyka.ru в обычном браузере.
2. Установите расширение для выгрузки кук в формате `cookies.txt`, например
   «Get cookies.txt LOCALLY» (Chrome/Edge/Firefox). На открытой странице
   azbyka.ru нажмите его и сохраните файл `cookies.txt` в папку программы.
3. Создайте в папке программы файл `config.toml` с двумя строками:
   ```
   [crawl]
   cookies_file = "cookies.txt"
   ```
4. Запустите `zapusk.bat` как обычно. Программа заметит новую настройку и
   сама поставит книги в очередь, ничего перекачивать не придётся.

Вход на сайте со временем истекает. Если в `status` снова растёт «нужен
вход», выгрузите куки заново и выполните `servis.bat retry`.

Файл `cookies.txt` — это ваш вход на сайт. Никому его не передавайте и не
кладите в репозиторий (он уже в `.gitignore`).

## 6. Как пользоваться архивом без интернета

- **Как сайт в браузере:** `prosmotr.bat` откроет http://localhost:8080/.
  Работают ссылки, картинки, аудиоплееры и встроенные видео (если они
  скачаны).
- **Поиск по всему тексту:** один раз выполните `servis.bat index`
  (на полном архиве это несколько часов). Потом поиск доступен в просмотре
  (кнопка «Офлайн-поиск»).
- **Каталог файлов без сервера:** `servis.bat catalog` создаёт
  `data\catalog\index.html` со списками книг (EPUB/FB2/PDF), аудио, нот и
  видео со ссылками прямо на файлы. Его можно открыть двойным щелчком.
  EPUB и FB2 удобно скопировать на электронную читалку.
- **Для всех вокруг:** `prosmotr.bat data set` раздаёт архив по локальной
  сети и Wi-Fi. С телефонов он открывается по адресу
  `http://IP-этого-компьютера:8080/`. Для этого подойдёт даже
  Raspberry Pi с диском (5–10 Вт, можно от аккумулятора или солнечной
  панели).

## 7. Видео с YouTube/RuTube/VK

Видео с собственного видеосервера портала (`tube.azbyka.ru`) скачивается
вместе со всем остальным. Ролики, встроенные со сторонних площадок,
собираются в отдельный список, и скачиваются отдельно:

```
pip install yt-dlp
servis.bat video
```

## 8. Обновление и проверка

- `python -m azbyka_reserv refresh --data E:\azbyka --older-days 90` ставит в
  очередь страницы старше 90 дней. Неизменившиеся страницы сервер не
  передаёт повторно. После этого запустите `zapusk.bat`.
- `servis.bat verify` проверяет, что все файлы на месте и целы.
  `python -m azbyka_reserv verify --fix ...` ставит битые на перекачку.

## 9. Резервные копии

Одна копия — не копия. Держите минимум две на разных дисках и в разных
местах. Копировать папку целиком (Windows):

```
robocopy E:\azbyka F:\azbyka /MIR /R:1 /W:1
```

Во время копирования сбор лучше остановить: база `state.sqlite` должна
быть согласованной.

## 10. Настройки

Все настройки по умолчанию с пояснениями лежат в
`azbyka_reserv/default_config.toml`. Чтобы что-то изменить, создайте
`config.toml` (образец — `config.example.toml`) и впишите только то, что
меняете. Частые случаи:

- скачать и форумы — убрать их из исключений;
- ограничить качество видео — `[peertube] max_height = 480`;
- не качать видео вообще — добавить исключение для `\.mp4`;
- ограничить скорость, чтобы не мешать домашнему интернету —
  `bandwidth_limit_kbps`.
